# MathRaceFX 🏎️  
**MathRaceFX** is an interactive race track game designed to help students practice math skills while having fun.  
Players answer **addition, subtraction, and multiplication** questions to control their car's speed and race against a constant-speed pace car.  

This project was developed as part of **COSC 602 - Assignment 3** at **Saskatchewan Polytechnic**.  

---

## 📌 Features  
✅ **Race Track Simulation** – Control your car by answering math questions.  
✅ **Speed Control** – Correct answers increase speed, incorrect answers slow you down.  
✅ **Time-Limited Questions** – Answer within **5 seconds** or lose momentum.  
✅ **Compete Against a Pace Car** – Try to finish the race before the reference car!  
✅ **Game Controls** – Start, Pause, Restart, and Exit options in the menu.  

---

## 📂 Project Files  
📜 **`StartRaceTrack.java`** – Main JavaFX application managing UI and game flow.  
📜 **`ControlBox.java`** – Handles math questions and user input validation.  
📜 **`CarPane.java`** – Manages car movement and race logic.  

---

## 🎮 How to Play  
1️⃣ **Start the game** by selecting "Start" from the menu.  
2️⃣ **Answer math questions** to accelerate the car.  
3️⃣ **Correct answers** increase speed **(+1 pixel per 1/10 sec)**.  
4️⃣ **Incorrect answers** slow you down **(-1 pixel per 1/10 sec)**.  
5️⃣ **Win by reaching the finish line before the pace car!**
